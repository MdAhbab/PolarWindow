The system behind the three screens

Fewer lines, more light, one typeface at two widths.

Hairlines become translucent so they read as edges catching light instead of paint. Every card is a tray with a lit core. Archivo stays, but as one variable file whose width axis gives the display sizes and the key figures their own voice. IBM Plex Mono keeps every stamp and coordinate.
